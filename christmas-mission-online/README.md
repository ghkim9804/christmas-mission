# 크리스마스 미션 LIVE

참가자들이 각자 휴대폰에서 최대 5개의 미션을 등록하고, 운영자가 실시간으로 취합해 **중복 없이 한 개씩 추첨**하는 웹앱입니다. 프런트엔드와 서버가 포함되어 있습니다.

## 주요 기능

- 참가자: 이름(별명), 미션 1~5개 제출 / 같은 기기에서 추첨 시작 전 수정
- 운영자: PIN 로그인, 참가자별 미션 조회, 실시간 미션 수 확인, 제출 마감/재개
- 추첨: 등록된 미션을 동일 확률로 1개씩 추첨, 중복 없음, 마지막 추첨 취소
- 기록: 추첨 이력, CSV 내보내기, 전체 초기화
- 실시간 동기화: 서버 전송 이벤트(SSE) 사용. 새로고침 필요 없음
- 데이터: 서버 파일(`data/missions.json`)로 저장

## 1. 내 컴퓨터에서 시험 실행

1. [Node.js 20 이상](https://nodejs.org/)을 설치합니다.
2. 이 폴더에서 터미널을 열고 다음을 실행합니다.

   ```bash
   npm start
   ```

3. 터미널에 표시된 `Admin PIN (automatically generated)`를 확인합니다.
4. 컴퓨터에서 `http://localhost:3000`을 엽니다. 운영자 화면은 `http://localhost:3000/admin`입니다.
5. 같은 Wi-Fi에 연결된 휴대폰에서는 컴퓨터의 **내부 IP 주소**를 사용합니다(예: `http://192.168.0.10:3000`). 방화벽에서 3000번 포트 접근을 허용해야 할 수 있습니다.

운영자 PIN을 고정하려면 시작 전 환경변수 `ADMIN_PIN`을 설정합니다. Windows PowerShell 예시:

```powershell
$env:ADMIN_PIN="여기에_충분히_긴_비밀_PIN"
npm start
```

macOS/Linux 예시:

```bash
ADMIN_PIN='여기에_충분히_긴_비밀_PIN' npm start
```

## 2. 인터넷에 배포하기 (Render 예시)

1. 이 폴더의 파일을 **GitHub 저장소**에 올립니다(`data/` 폴더는 올리지 마세요).
2. [Render](https://render.com/) 계정에서 **New → Blueprint**를 선택하고 저장소를 연결합니다.
3. 포함된 `render.yaml` 파일로 웹 서비스를 생성합니다.
4. Render 서비스의 **Environment**에서 `ADMIN_PIN` 항목의 값을 확인합니다. 이 값은 운영자만 보관합니다.
5. 배포 후 발급되는 `https://...onrender.com/` 링크를 참가자에게 공유합니다. 운영자는 동일 링크 뒤에 `/admin`을 붙여 접속합니다.

**중요:** Render 무료 플랜의 파일 저장공간은 영구적이지 않습니다. 재배포/재시작 시 `data/missions.json`이 사라질 수 있습니다. 파티 진행 전에는 서비스를 활성 상태로 유지하고, 진행 중에는 **데이터 CSV 저장** 기능으로 자주 백업하세요. 장기간 안정적인 운영이나 복구가 필요하면 영구 디스크를 제공하는 호스팅 또는 데이터베이스 연결이 필요합니다. 무료 인스턴스는 비활성 시 잠들 수 있어 첫 접속이 느릴 수 있습니다.

## 안내 / 제한

- 링크는 모두에게 공개되는 **단일 파티방**입니다. 다른 파티를 운영할 때는 서버를 별도로 배포하거나 전체 초기화하세요.
- 기본적으로 미션을 **제출한 참가자 수**와 미션 수가 보이며 참가자 이름·미션 목록은 운영자 PIN으로 보호됩니다. 단, 추첨된 미션 및 제안자 이름은 참여 화면에도 데이터로 전송되므로 익명성 보장이 필요할 경우 기능을 변경해야 합니다.
- 참가자 식별은 각 브라우저에 저장된 ID 기반입니다. 다른 브라우저나 기기를 사용하면 다른 참가자로 간주합니다. 강력한 사용자 인증/중복 제출 방지 기능은 아닙니다.
- 미션별 균등 확률로 추첨되므로 미션을 더 많이 제출한 참가자의 미션이 뽑힐 확률이 높습니다. 참가자별 균등 추첨을 원하면 알고리즘 변경이 필요합니다.
- 운영자 PIN은 길고 예측하기 어려운 문자열로 설정하세요. 실제 인터넷 서비스에서는 HTTPS를 사용하세요.
- 제출된 내용을 참가자 기기에서는 직접 지울 수 없으며 운영자가 전체 초기화할 수 있습니다. 서버 데이터는 목적에 맞게 관리하고 파티 후 삭제하세요.
